Section 10.1 · P.10.2

Concept and Basic Operations of Matrices矩陣的概念與基本運算

A matrix is a mathematical tool that records numbers in rows and columns and enables us to operate on whole datasets at once. Addition, scalar multiplication, and equality form the foundation of everything that follows. 矩陣是一種把數字按「列」與「行」排列的數學工具，使我們能對整組資料作整體運算。矩陣的加減、純量乘法與相等是整個單元的基石。

A Concept of Matrices 矩陣的概念

Definition定義

A matrix (plural: matrices) is a rectangular array of numbers arranged in rows and columns, enclosed by a pair of brackets. 矩陣（複數：matrices）是由數字排成的長方形陣列，數字按「列」（row）與「行」（column）排列，並以一對括號括起來。

Elements and order · 元素與階

Each number inside a matrix is called an element (or entry). If a matrix has m rows and n columns, its order (or dimension) is m × n, and it is called an m × n matrix. Capital letters name matrices, and small letters with double subscripts name elements: aij is the element in the i‑th row and j‑th column. 矩陣中的每個數稱為「元素」。若矩陣有 m 列、n 行，其「階」（或維數）為 m × n，稱為 m × n 矩陣。矩陣以大寫英文字母命名，元素則以小寫字母附帶雙下標表示：aij 為第 i 列第 j 行的元素。

C Equality of Matrices 矩陣的相等

Definition定義

Two matrices A and B are equal (written A = B) if and only if they have the same order and their corresponding elements are equal. That is, aij = bij for all i and j. 兩個矩陣 A 與 B「相等」（記作 A = B）當且僅當兩者的階相同，且所有對應元素均相等。

y − 2 = 5  ⟹  y = 7

D Addition and Subtraction of Matrices 矩陣的加法與減法

Definition定義

Let A = (aij) and B = (bij) be two m × n matrices.
• The sum A + B is the m × n matrix with entries aij + bij.
• The difference A − B is the m × n matrix with entries aij − bij. 設 A、B 為兩個同階的 m × n 矩陣。其和 A + B 與其差 A − B 均為 m × n 矩陣，計算方法為逐一將對應元素相加或相減。

Crucial Rule必記守則

Matrices can be added or subtracted if and only if they have the exact same order. If the orders differ, the operation is undefined. 矩陣能夠相加或相減的「充要條件」是兩者必須同階。若階不同，加減運算無定義。

Section 10.2 · P.10.16

Multiplication of Matrices矩陣乘法

Matrix multiplication is defined by a "row-times-column" dot product to compactly calculate systems of linear combinations. It possesses rich algebraic structures, but violates familiar real-number properties such as commutativity. 矩陣乘法以「列乘行」的內積方式定義，以便緊湊地計算線性組合。它具有豐富的代數結構，但不再滿足實數運算中常見的乘法交換律等性質。

A Definition & Order Compatibility 乘法法則與階的相容性

Definition定義

If A = (aij) is an m × n matrix and B = (bij) is an n × p matrix, their product AB is the m × p matrix C = (cij) defined by cij = ai1b1j + ai2b2j + ⋯ + ainbnj = Σr=1n airbrj for all i = 1, 2, … , m and j = 1, 2, … , p. 設 A 為 m × n 矩陣、B 為 n × p 矩陣，則乘積 AB 為 m × p 矩陣，其第 ij 個元素由 A 的第 i 列各元素與 B 的第 j 行各對應元素相乘後求和所得。
(m × n) · (n × p) = (m × p)

Condition: The product AB is defined if and only if the number of columns in A equals the number of rows in B.
Resulting Order: The resulting matrix has (rows of A) × (columns of B). （1）乘積 AB 有定義的充要條件：A 的行數必須等於 B 的列數；（2）乘積的階為 A 的列數 × B 的行數。

B Four Fatal Traps & Properties 乘法四大陷阱與性質

Four Fatal Traps in Matrix Multiplication矩陣乘法四大必避陷阱

1. Not Commutative: In general, AB ≠ BA. Even when both exist and have identical order, they are usually unequal.一般而言 AB ≠ BA，切不可隨意交換次序。

2. Zero Divisors Exist: AB = 0 does NOT imply A = 0 or B = 0! Two non-zero matrices can multiply to yield the zero matrix.兩個非零矩陣相乘可以是零矩陣！因此 AB = 0 絕不代表 A = 0 或 B = 0。

3. Cancellation Law Fails: AB = AC does NOT imply B = C (unless A is invertible).一般情況下不能「兩邊消去 A」：AB = AC 不能推出 B = C。

4. Algebraic Expansions Differ: (A + B)2 = A2 + AB + BA + B2 ≠ A2 + 2AB + B2 (unless AB = BA). Also (A + B)(A − B) = A2 − AB + BA − B2 ≠ A2 − B2.常規公式如 (A+B)² = A² + 2AB + B² 不成立，因為交叉項 AB 與 BA 無法合併為 2AB。

C ⭐ Mathematical Induction on Matrix Powers 數學歸納法證明矩陣次方

HKDSE M2 Signature Exam Question · 文憑試標誌性大題

In HKDSE M2, questions asking to prove a formula for An by Mathematical Induction (M.I.) appear almost every year. Always adhere strictly to the 5-step standard template: (1) Define proposition P(n); (2) Base step n = 1; (3) Inductive hypothesis n = k; (4) Inductive step n = k + 1 using Ak+1 = AkA; (5) Formal conclusion. 以數學歸納法證明矩陣次方 An 是 DSE M2 必考題型。答題時務必遵循標準 5 步結構：設命題 P(n)、驗證 n=1、假設 n=k 成立、利用 Ak+1 = AkA 證明 n=k+1 成立、作結。

Section 10.3 · P.10.30

Determinants行列式

A determinant assigns a single scalar value to any square matrix. It serves as the primary test for whether a matrix possesses an inverse, appears geometrically as oriented volume/area scaling factor, and provides an efficient tool for solving systems of linear equations. 行列式將一個純量數值指派給每一個方陣。它是檢驗方陣是否具備逆矩陣的核心指標，在幾何上代表有向面積或體積的縮放比，同時也是解線性方程組的高效工具。

A Order 2 & Order 3 Determinants (Rule of Sarrus) 二階與三階行列式（薩拉士法則）

Definition定義

To every square matrix A, there is an associated scalar called the determinant of A, denoted |A| or det A.
• For a 2 × 2 matrix a11a12a21a22 = A: |A| = a11a22 − a12a21 — the product of the main diagonal minus the product of the other diagonal. 二階行列式由「主對角線兩數之積」減去「副對角線兩數之積」。

Vital Warning重要警示

The vertical bars | | represent the determinant operation, NOT the absolute-value function! A determinant can be negative or zero. Furthermore, determinants are defined only for square matrices ($n imes n$). 行列式的豎線符號「| |」不是絕對值！行列式的值完全可以是負數或零。此外，只有「方陣」才有行列式，長方形矩陣無行列式。

Rule of Sarrus (Order 3 Only) ／ 薩拉士法則（僅適用於三階）

To compute a 3 × 3 determinant, copy the first two columns to the right. Sum the three down-right products and subtract the three up-right products: 將首兩行複製並排列在右側，把三個「由左上至右下」的乘積相加，再減去三個「由左下至右上」的乘積：

a11a12a13a21a22a23a31a32a33 a11a12 a21a22 a31a32
+ 3 DOWN-RIGHT PRODUCTS (正項)
+ a11a22a33
+ a12a23a31
+ a13a21a32
− 3 UP-RIGHT PRODUCTS (負項)
− a13a22a31
− a11a23a32
− a12a21a33

Note: Rule of Sarrus applies to 3 × 3 determinants ONLY. It does NOT work for 4 × 4 or higher.注意：薩拉士法則只適用於三階行列式，不可推廣至四階或以上。

B Minors and Cofactors 子行列式與餘因子

Definition定義

Let A = (aij) be a square matrix of order n.
• The minor of aij, denoted Mij, is the determinant of the order (n−1) submatrix obtained by deleting the i‑th row and j‑th column of A.
• The cofactor of aij, denoted Cij, is defined by: Cij = (−1)i+j Mij 元素 aij 的「子行列式」Mij 是劃去第 i 列與第 j 行後所剩矩陣的行列式；「餘因子」Cij 則是附加符號 (−1)i+j 後的子行列式。

Section 10.4 · P.10.42

Inverse of a Matrix逆矩陣

For real numbers, any non-zero number $a$ has a reciprocal $a^{-1} = 1/a$. For square matrices, the determinant dictates invertibility: a matrix is invertible if and only if its determinant is non-zero. The classical adjoint formula provides an explicit method to construct the inverse. 在實數中，任何非零數 a 均有倒數 a−1 = 1/a。對於方陣而言，行列式決定了其可逆性：矩陣可逆當且僅當其行列式不為零。伴隨矩陣公式則提供了求出逆矩陣的精確途徑。

A Transpose of a Matrix 矩陣的轉置

Definition定義

Let A = (aij) be an m × n matrix. The transpose of A, denoted AT (or At), is the n × m matrix formed by interchanging the rows and columns of A. That is, if AT = (bij), then bij = aji. 設 A 為 m × n 矩陣，把 A 的列與行互換所成的 n × m 矩陣稱為 A 的「轉置矩陣」，記作 Aᵀ。即 Aᵀ 的第 ij 個元素等於 A 的第 ji 個元素。

(a)(AT)T = A
(b)(A ± B)T = AT ± BT
(c)(λA)T = λAT
(d)(AB)T = BTATorder reverses · 相乘轉置次序倒轉
(e)IT = I

A square matrix M is called a symmetric matrix if MT = M. It is called skew-symmetric if MT = −M. 若方陣 M 滿足 Mᵀ = M，則稱為「對稱矩陣」；若滿足 Mᵀ = −M，則稱為「反對稱矩陣」。

B Concept of the Inverse of a Matrix 逆矩陣的概念與可逆條件

Definition定義

Let A be a square matrix of order n and I the identity matrix of order n. If there exists a matrix B such that: AB = BA = I then B is called the inverse of A, denoted by A−1.
• If A−1 exists, A is called non-singular (or invertible).
• If A−1 does not exist, A is called singular. 設 A 為方陣。若存在矩陣 B 使得 AB = BA = I，則稱 B 為 A 的逆矩陣，記作 A−1。當逆矩陣存在時，稱 A 為非奇異（可逆）矩陣；否則稱 A 為奇異矩陣。

Fundamental Theorem of Invertibility可逆性基本定理

A square matrix A is non-singular (invertible) if and only if its determinant is non-zero: A is invertible  ⟺  |A| ≠ 0 Equivalently:   A is singular  ⟺  |A| = 0.
Furthermore, if the inverse of A exists, it is unique. 方陣 A 可逆的充要條件是其行列式不為零：A 可逆 ⟺ |A| ≠ 0。若 |A| = 0 則 A 為奇異矩陣，不存在逆矩陣。且逆矩陣一旦存在，必然唯一。

❌ Fatal Error 4 · 致命錯漏
Forgetting Transpose in Adjoint:
Calculating cofactors Cij and writing A−1 = 1|A| (Cij) without transposing.

算出 9 個餘因子後，直接除以行列式，忘記將矩陣轉置！

✓ Correct DSE Standard · 正確做法
Always Transpose the Cofactor Matrix:
adj A = (Cij)T.
Entry (row i, col j) of adj A is Cji!

餘因子的下標必須對角線翻轉，才構成伴隨矩陣。

❌ Fatal Error 5 · 致命錯漏
Assuming Determinant Distributes over Sum:
Assuming |A + B| = |A| + |B|.

誤以為兩個矩陣相加的行列式等於各自的行列式相加。

✓ Correct DSE Standard · 正確做法
Multiplication ONLY:
|AB| = |A||B| holds, but |A + B| ≠ |A| + |B|.
To find |A + B|, add the matrices first, then compute.

行列式只對「乘法」保全積，對「加法」絕無此性質。

❌ Fatal Error 6 · 致命錯漏
Omitting Identity Matrix in Polynomials:
Writing A2 − 3A + 2 = 0 or factoring as A(A − 3) = −2.

在矩陣多項式中遺漏單位矩陣 I，將純量 2 與矩陣混淆。

✓ Correct DSE Standard · 正確做法
Must Include Identity Matrix I:
Always write A2 − 3A + 2I = 0.
Factoring: A(A − 3I) = −2I ⟹ A−1 = −½(A − 3I).

矩陣不可與純量直接相加減，常數項必須附加單位矩陣 I！

Chapter Summary · 全章精華

The Entire Chapter on One Page全章重點概念與定理總結

Ten core mathematical pillars summarize all of Chapter 10. Being able to state each property and recall its preconditions guarantees mastery of the curriculum. 十項核心定理與性質涵蓋全章內容。能熟練默寫每一條性質並掌握其適用條件，即可穩操勝券。

1Matrix Concept & Order 概念與階

An m × n matrix has m rows, n columns. aij sits in row i, column j. 矩陣由 m 列 n 行構成，階為 m × n。

2Basic Operations 加減與純量乘法

Same order matrices add and subtract entry-wise. λA scales every single entry by scalar λ. 同階矩陣逐項加減；純量乘法乘遍所有元素。

3Multiplication Rule 矩陣乘法法則

cij = Σ aikbkj. Product exists ⟺ columns of A = rows of B. 列乘行相加；前行等於後列時方可相乘。

4Multiplication Properties 乘法性質

AI = IA = A, associative A(BC) = (AB)C, but generally AB ≠ BA. 單位矩陣如同 1；結合律成立，但交換律不成立。

5Order 2 & 3 Determinants 二階與三階行列式

Order 2: ad − bc. Order 3: 6 terms, easily evaluated via the Rule of Sarrus. 二階主減副對角線積；三階可用薩拉士法則。

6Laplace Expansion 餘因子展開

Cij = (−1)i+jMij. Expand along the row or column containing the most zeros! 餘因子依棋盤正負交替；選最多 0 的行或列展開。

7Determinant Scaling & Product 行列式性質

|AB| = |A||B|,  |kA| = kn|A|,  |AT| = |A|. 積的行列式等於行列式之積；純量提出取 n 次方。

8Classical Adjoint Inverse 伴隨矩陣求逆

A−1 = 1|A| adj A where adj A = (Cij)T. Invertible ⟺ |A| ≠ 0. 伴隨矩陣為餘因子矩陣的轉置；非奇異 ⟺ |A| ≠ 0。

9Inverse Properties 逆矩陣的性質

(AB)−1 = B−1A−1,  (AT)−1 = (A−1)T,  |A−1| = 1|A|. 乘積求逆次序反轉；轉置與求逆可互換次序。

10Similarity & Induction 對角化與數歸法

If P−1AP = D, then An = P Dn P−1. Use M.I. to prove power formulas. 相似對角化連串對消求 An；以數歸法嚴格證題。
